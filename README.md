# AI工具集导航网站

一个现代化的AI工具导航网站，包含工具展示、用户系统、每日AI快讯管理等功能。

## 🌟 功能特性

### 前端功能
- **工具导航**: 分类展示各种AI工具
- **搜索功能**: 快速查找所需工具
- **用户系统**: 注册、登录功能
- **每日AI快讯**: 浏览最新AI行业动态
- **响应式设计**: 支持各种设备访问

### 管理后台
- **管理员权限**: 基于角色的访问控制
- **新闻管理**: 添加、编辑、删除AI快讯
- **内容发布**: 支持文本、图片、链接等多种内容类型
- **数据统计**: 浏览量、点赞数等统计信息
- **批量操作**: 支持批量删除、导出等功能
